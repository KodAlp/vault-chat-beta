# MarkItDown only — lightweight, CPU-only, installs in seconds.
# Pandoc is used for .tex when present on PATH (system tool, not a Python
# package) but isn't a hard requirement — convert.py degrades gracefully
# when it's missing, same as the tools below.
#
# Versions pinned to what this repo was last tested against —
# reproducible installs, and a version bump is now a visible, reviewable
# diff instead of a silent drift. Bump deliberately, not by habit.
markitdown[all]==0.1.6

# YouTube transcript ingest (youtube_transcript.py) — subtitle/caption
# fetching only, never downloads video/audio. Pinned like the rest, but
# yt-dlp ships near-daily releases to keep up with YouTube's own changes —
# if YouTube import starts failing, bumping this first is the usual fix.
yt-dlp==2026.7.4

# Linkten içe aktarma (web sayfası kolu): ana-içerik ayıklama.
# MarkItDown'ın HTML'i de "çevirdiği" doğru ama nav/reklam/gövde-dışı öğeleri
# ayıklamıyor — trafilatura tam olarak bu problemi çözüyor. Hafif, saf Python.
trafilatura==2.2.0

# MathML -> LaTeX fallback for extract_web.py's math handling
# (mathml_convert.py) — used only when a <math> element carries neither an
# alttext nor a TeX annotation (see that module's docstring for the two
# preferred, source-preserving paths tried first). Pure Python, pulls only
# lxml (already a trafilatura dependency).
py-asciimath==0.3.0

# pypdf: page count for convert.py's escalation heuristic. MarkItDown does not
# reliably emit the form-feed separator the old proxy counted, so the heading
# check silently never ran on real books. Lightweight, pure Python; markitdown
# already pulls it transitively, pinned here because convert.py imports it
# directly.
pypdf==6.21.2

# pdf_tounicode.py: reads glyph names from the embedded fonts of old TeX PDFs
# (CFF tables via fontTools.cffLib, Adobe Glyph List via fontTools.agl) to give
# them a correct /ToUnicode before conversion. Pure Python wheel. Pinned under
# its canonical casing on purpose: src/lib/server/pythonModules.ts derives the
# import name from this file by replacing "-" with "_", and the import name is
# "fontTools" (a lower-case "fonttools" line would be checked as "fonttools"
# and always look missing). Without it the repair degrades (fewer glyph names
# resolve), it never fails the conversion.
fontTools==4.63.0

# Marker and Docling are implemented in convert.py but stay OPTIONAL: they pull
# PyTorch and multi-GB model weights, and the user's RAM belongs to Ollama
# first. convert.py detects their
# absence via ImportError and reports a clear "not installed" message rather
# than crashing or silently degrading output quality.
#
# A math-heavy or scanned PDF genuinely needs one of them — MarkItDown returns
# well-formed Markdown with the equations destroyed. Opt in with:
