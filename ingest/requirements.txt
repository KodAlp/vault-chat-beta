trafilatura

# Aşama 10 (#2): MathML -> LaTeX fallback for extract_web.py's math handling
# (mathml_convert.py) — used only when a <math> element carries neither an

# preferred, source-preserving paths tried first). Pure Python, pulls only

# pypdf: page count for convert.py's escalation heuristic. MarkItDown does not

# already pulls it transitively, pinned here because convert.py imports it
# directly.
pypdf
